Proyek Saya

Projek SUTET

Membuat miniatur SUTET termasuk menurunkan tegangan 220V ke 5V dengan menggunakan beberapa komponen diantaranya:

  • Terminal Kabel
  • Kabel NYAF
  • Diode 4007 (pe)
  • Kapasitor 2,2 uf 400V
  • Elco 470 uf 25V
  • Resistor 220K Ohm
  • Diode Zener 5,6V

Sistem Deteksi Kondisi Aman

Sistem logika digital (SOP/POS, K-Map) dengan sensor gas MQ2 untuk memicu indikator bahaya di area pabrik. Fokus pada pemahaman dasar desain keamanan.

Rangkaian Timer Kapasitor

Proyek dasar elektronika semester 2. LED menyala otomatis ±30 detik menggunakan prinsip delay RC (Resistor-Kapasitor) dan switching MOSFET.

Analisis Regresi Linear

Project komputasi numerik. Analisis hubungan jumlah penduduk vs pengangguran di Banten (2023–2024) menggunakan Python (library sklearn).

Metode Node & Mesh

Project ini merupakan bagian tugas akhir praktikum rangkaian listrik, dengan menganalisis sebuah rangkaian searah dua sumber independen dan satu sumber dependen menggunakan metode Node dan Mesh.

Pulse Modulation & Pulse Code Modulation

Project ini bagian tugas akhir praktikum Dasar Telekomunikasi, untuk menganalisis hasil modulasi dari pulse modulation dan pulse code modulation

LED Chesar dengan Arduino

Projek ini bagian tugas akhir Mata Kuliah Dasar Mikroprosesor dengan membuat led chesar sebagai penunjuk jalan di stasiun kereta api

Tempat Sampah Closed Loop

Projek Akhir Praktikum Dasar Sistem Kendali, Merancang dan mengembangkan tempat sampah otomatis berbasis sistem kendali closed-loop menggunakan Arduino Uno, sensor ultrasonik, servo motor, dan LCD I2C untuk meningkatkan higienitas serta memantau kapasitas sampah secara real-time.
